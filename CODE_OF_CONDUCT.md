# Code of conduct

Be respectful, specific, and evidence-led. Critique code and claims, not people.
Do not publish another person's private information, credentials, or security
report. Harassment, discrimination, and threats are not welcome.

Maintainers may edit or remove contributions that violate these rules and may
restrict participation when needed to keep the project safe and constructive.
For sensitive conduct reports, use the repository owner's private GitHub contact
instead of a public issue.
