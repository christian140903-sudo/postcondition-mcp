# Security policy

## Supported versions

Security fixes are provided for the latest published minor line while the
project is below `1.0`.

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository. Please do not
open a public issue with exploit details, credentials, local paths, or private
data.

Include:

- affected version and operating system;
- a minimal reproduction;
- the security boundary you expected;
- potential impact;
- whether the report can be credited publicly.

You should receive an acknowledgement within seven days. No bounty is promised.
Coordinated disclosure is appreciated.

The documented security boundary and known limitations are in
[`docs/SECURITY-MODEL.md`](./docs/SECURITY-MODEL.md) and
[`docs/LIMITATIONS.md`](./docs/LIMITATIONS.md).
